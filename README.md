# 🐐 Product Void · Хоосон дэвсгэр

**Claude Code дотор ажилладаг видео эдитийн skill.** Барааг дэвсгэрээс нь салгаж, нэг өнгийн хоосон дэвсгэр дээр тавина. Үнэтэй брэндийн зар шиг цэвэрхэн, нам гүм.

Reels, TikTok-д бэлэн 1080×1920 MP4 гаргана. GOAT Academy-гийн 14 эдитийн стилийн нэг.

---

## Юунд тохирох вэ?

- **Тохирно:** онлайн дэлгүүр, бараа, үнэртэн, гоо сайхны бүтээгдэхүүн, гоёл чимэглэл
- **Тохирохгүй:** өрөө, үл хөдлөх, олон хүнтэй бичлэг

---

## Шаардлага

- **Claude Code** (desktop app эсвэл terminal), Claude Pro / Max эрхтэй
- **Mac эсвэл Windows**
- **ffmpeg** болон **uv**. Байхгүй бол Claude өөрөө шалгаад, суулгах командыг хэлж өгнө.
- Анх удаа ажиллуулахад хайчлах загвар (~170 MB) нэг удаа татагдана.

---

## Суулгах

**Хамгийн хялбар:** Claude Code-оо нээгээд энэ мөрийг хуулж бичнэ:
```
Энэ plugin-ийг суулгаад өг: https://github.com/SaagiiSG/goat-product-void
```
Claude өөрөө суулгана. Дараа нь `/reload-plugins` гэж бичих эсвэл Claude Code-оо хаагаад дахин нээнэ.

**Эсвэл өөрөө:** Claude Code дотор энэ 2 мөрийг ээлжлэн бичнэ:
```
/plugin marketplace add SaagiiSG/goat-product-void
/plugin install goat-product-void@goat-product-void
```

**Шинэ хувилбар гарвал:** Claude-д "goat-product-void plugin-ийг шинэчил" гэж хэлэхэд болно.

> **For Claude Code:** to install this plugin, run `claude plugin marketplace add SaagiiSG/goat-product-void` and then `claude plugin install goat-product-void@goat-product-void`, then tell the user to type `/reload-plugins`. To update it: `claude plugin marketplace update goat-product-void` and then `claude plugin update goat-product-void@goat-product-void`.

## Хэрэглэх

1. Видео бүрд **шинэ хоосон хавтас** үүсгэ.
2. Claude Code-ийг тэр хавтсанд нээ.
3. Бичнэ: `/goat-product-void:goat-product-void` эсвэл энгийнээр: **"энэ барааг хоосон дэвсгэр дээр тавиад зар хийгээд өг"**
4. Бичлэгээ чирж оруулаад барааны нэр, үнээ бичнэ.
5. Claude юу хийхээ товч хэлнэ. Таалагдвал "ок" гэхэд л болно.
6. `output/product-void.mp4` бэлэн. Instagram, TikTok руу шууд оруулна.

---

## Дуу

- **Дуу эффект** автоматаар орно. Кодоор хийсэн учир лицензийн асуудалгүй. Хэрэггүй бол "дуу эффектгүй болго" гэж хэлэхэд болно.
- **Өөрийн дуугаар ярих (voice-over):** утсаараа дуугаа бичээд (voice memo) өгнө. Таны дуу гарах үед бичлэгийн дуу, хөгжим өөрөө намсна.
- **Хөгжим:** Instagram, TikTok апп дотроос нэмбэл зохиогчийн эрхийн асуудалгүй.
